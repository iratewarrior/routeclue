# RouteClue: назначение и границы

Имя RouteClue принято владельцем 2026-10-30. Предыдущая идея diagnostic-only
alpha отменена: **kill switch, маршруты и split DNS остаются**.
Актуальный инженерный план — [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md).

## Зачем

Инструмент нужен прежде всего самому владельцу. Помогает разбираться, почему
конкретный ресурс недоступен с VPN/прокси, и явно применять нужные сетевые
настройки. Пригоден для личного VPN ради доступа к сервисам, ограничений по IP,
корпоративных ресурсов и локальной сети. Востребованность на рынке не gate.

## Что делает

GUI и CLI с общей библиотекой: explain/doctor/status, kill switch, восстановление
маршрутов, split DNS, config, snapshot/diff и verify. Изменения сети запускаются
явно с системной авторизацией; обычная диагностика без root. В интерфейсе есть
поле адреса и Paste, причины ошибок и состояние on/off/unknown.

Kill switch на PF сохраняется и требует технической проверки, а не удаления.
Не затираем чужие правила и не отключаем глобально PF. Root bypass, существующие
states и непроверенные IPv6-сочетания — документированные ограничения.

Универсальность — не привязка к одному VPN-серверу/провайдеру, читаемые настройки
и честные границы совместимости. Это не обещание работы со всеми VPN.
Системный route не доказывает путь браузера с собственным proxy. Таймаут не
доказывает цензуру, 403 — ограничение по стране. Отделяем наблюдения от гипотез.

## Что сейчас не нужно

Интервью, pilot recruitment, конкурентное позиционирование, метрики роста,
облако, аккаунты, маркетинговый сайт, платная подписка и собственный VPN.
Фоновый автохилинг не обязателен. Дополнительные TCP/TLS/HTTP проверки и профили
можно добавлять после работоспособного базового набора.

Будущие active probes: ограниченные timeout, отмена, A/AAAA; обнаруженный
неподдерживаемый proxy не должен незаметно обходиться direct-запросом. HTTP
без автопереходов по redirects и без credentials. Экспорт очищается перед
передачей; никаких автоматических загрузок логов.

## Готовность

Решение работает в проверенных окружениях, собирается, имеет regression tests,
внятные сообщения и ограничения, README с установкой/удалением и MIT LICENSE.
Затем выкладываем на GitHub. Не ждём подтверждения спроса.
