# Changelog

## 0.2.0 (RouteClue)

### Rebranding & Architecture
- **Unified Rebranding**: Migrated package, products, targets, imports, and CLI to `RouteClue` (`routeclue` CLI, `RouteClue.app`, `RouteClueSelfTest`).
- **Configuration Store & Migration**: Configuration saved to `~/Library/Application Support/RouteClue` with seamless read-only fallback to legacy `TunnelGuard`. JSON parsing failures throw explicit `ConfigError.corrupted` without silently falling back or corrupting existing settings.

### Security & Hardening
- **Isolated PF Anchors**: Kill switch operates exclusively in `com.apple/routeclue` with active ruleset reachability checks; eliminates global `/etc/pf.conf` overwrites and avoids global `pfctl -F all` or `pfctl -d`.
- **Fail-Closed Validation**: Pre-flight validation via `pfctl -n` fails closed on syntax or execution errors.
- **Inlined Table Generation**: Allow-list paths are read as data, strictly validated, and inlined directly into PF table definitions.
- **Reference Token Lifecycle**: Captured tokens from `pfctl -E` are stored and released idempotently (`pfctl -X`) upon disable.
- **Resolver Ownership Protection**: Zone files written with explicit `# Generated by RouteClue` headers; deletion refused unless ownership is verified.
- **Command Injection Protection**: Shell arguments quoted via `Shell.quote`; batches executed with `set -e` without masking errors.
- **Strict IP/CIDR & DNS Validation**: Elimination of `compactMap` parsing omissions in IPv4, CIDR, and nameserver validators; support for IPv6 nameservers without colon truncation.

### Features & Diagnostics
- **Path Explainer Ordering**: Tunnel traffic correctly classified as `viaTunnel` before applying direct allow-list checks.
- **Interface IP Disclosure**: Clarified interface address reporting to distinguish interface IPs from measured live socket endpoints.
- **Duplicate-Safe Policy Verification & Drift**: Elimination of crashes on duplicate routes in `PolicyVerifier` and `SnapshotDiff`.
- **GUI Modernization**: Menu bar app updated with explicit Paste button, debounced/coalesced background refreshes, live config reloading, and comprehensive error logging in Heal All.
